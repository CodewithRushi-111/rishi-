# Rushikesh Naik — 3D Portfolio Landing Page

A first-pass landing page inspired by the supplied reference portfolio. It keeps the same general experience: fixed minimal nav, oversized editorial hero typography, interactive 3D displacement sphere, subtle grid/grain, metadata, and a scroll cue.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## What is intentionally not final yet

Projects, full tech stack display, About, contact details, and project live/GitHub links are placeholders. Those can be filled in after the landing page is approved.

The visual direction was based on the public reference portfolio and its open-source implementation. The reference repository is a fork of Hamish Williams' portfolio; the original repository requests credit when its design is used largely unmodified.
